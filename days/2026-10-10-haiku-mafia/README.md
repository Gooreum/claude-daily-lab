# haiku-mafia — Claude Haiku 5.5 다섯 명의 마피아 게임

## 1. 무엇을 만들었나
Python CLI `mafia.py`. Claude Haiku 5.5 다섯 명(아라·보검·찬우·다은·은호)이 마피아 1, 탐정 1, 시민 3으로 나뉘어 밤·낮·투표를 자동으로 진행한다. 플레이어 한 명의 한 발언이 `claude -p` 호출 하나이고, JSON 스키마 구조화 출력으로 "말(say)"과 "대상(target)"을 받는다. 결과는 터미널에 생중계되고 역할·비밀 조사 결과까지 담긴 기록이 `games/*.md`로 남는다. `--dry-run`이면 시드 고정 대본 봇이 대신 플레이해 키·네트워크 없이 엔진을 돌릴 수 있다.

## 2. 왜 만들었나
2026-10-07 [Claude Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5) 출시(입력 $0.10/출력 $0.50 per MTok, Claude Code 2.1.293에서 기본 Haiku)와 Claude Code `-p`의 `--json-schema` 구조화 출력을 같이 써 보고 싶었다. "싸고 빠른 모델 다섯이 서로 거짓말하면 얼마나 재미있나"가 질문이었고, 한 판에 수십 번의 호출이 들어가도 몇 센트면 되는지 확인하는 것도 목적이었다. 앞선 결과물들이 "유용하지만 노잼"이라는 평을 들은 날의 반성문이기도 하다.

## 3. 어떻게 만들었나
1. **플레이어 = CLI 호출**: API 키 없이 Claude Code의 로그인 그대로 `claude -p`를 쓴다. `--system-prompt`에 이름·역할·역할별 조언, 프롬프트에 공개 로그와 본인만 아는 메모(탐정 조사 결과), `--json-schema`로 `{say, target}`을 강제하되 `target`은 그 시점 생존자 이름의 `enum`. `--tools ""`, `--max-turns 3`(구조화 출력이 턴을 하나 더 쓴다), `--effort low`, `--no-session-persistence`로 가볍게.
2. **엔진**: `Game`이 밤(마피아 지목·탐정 조사는 병렬 호출) → 낮(발언은 순서대로, 서로의 말을 보며) → 투표(병렬) → 과반 처형을 돌린다. 첫 발언자는 매일 바뀐다. `winner()`가 승패를 판정한다.
3. **대본 봇** (`ScriptedBackend`): 시드 고정 난수. 탐정은 조사로 찾은 마피아에게 표를 모은다. 테스트와 `--dry-run`, 그리고 모델 응답이 깨졌을 때의 대체 선수로 쓴다.
4. **막힌 지점 — `--bare`**: 처음엔 훅을 건너뛰려 `--bare`를 붙였더니 18번 모두 "Not logged in"이 났다. `--bare`가 저장된 로그인 정보까지 건너뛴다. 플래그를 빼고, `is_error` 응답을 명시적으로 실패로 처리해 대본 봇이 대신 답하되 stderr에 이유를 남기게 했다. 테스트로 고정했다.
5. **첫 판**: 보검(탐정)이 "다은의 말끝이 흔들렸다"고 몰아가다 셋에게 "그 확신이 제일 수상하다"며 처형당했다. 마피아 은호는 그 흐름에 묻어가 한마디로 이겼다. 11번 호출, 44초, $0.033.

## 4. 사용법
```bash
cd days/2026-10-10-haiku-mafia
python3 mafia.py                       # Haiku 5.5 다섯 명이 한 판 (약 1분, 수 센트)
python3 mafia.py --seed 42             # 같은 역할 배정으로 다시 (말은 매번 다르다)
python3 mafia.py --dry-run --seed 7    # 모델 없이 대본 봇 (키·네트워크 불필요, 완전 재현)
python3 mafia.py --rounds 6 --model claude-sonnet-5-5 --no-save
```
기록은 `games/<UTC시각>-haiku-seed<N>.md`에 남고 비밀 역할·조사 결과도 적힌다(gitignore). 한 판 샘플은 [sample-game.md](sample-game.md).

## 6. 한계와 다음 아이디어
- 5인·1마피아 고정이라 마피아가 첫 밤에 탐정을 맞히거나 시민이 탐정을 처형하면 금방 끝난다. 7인(마피아 2, 의사 1)과 의사의 보호를 넣으면 길어진다.
- 각 발언은 독립 호출이라 플레이어에게 "기억"이 없다. 공개 로그를 매번 다시 보내는 방식이라 라운드가 길어지면 토큰이 늘어난다.
- 관전 재미는 모델의 연기력에 달려 있다. 발언 길이·말투를 `--system-prompt`로 바꿔 보거나 역할마다 다른 모델(마피아만 Sonnet)을 붙이면 비대칭 게임이 된다.
- 다음: 사람이 한 자리에 앉는 `--human 아라`, 여러 판 돌려 마피아 승률 통계, 투표 전에 한 번 더 반박 기회.
