- 한 줄: 밤새 혼자 돌린 Claude 작업이 끝난 뒤, 결과가 진짜 만들어졌는지 확인해 주는 검사 도구
- 왜: 밤샘 작업이 "정상 종료"로 보이는데 실제로는 빈 파일만 남기거나 시작도 못 한 사례가 소개됐다.
- 쓰는 법: 점검할 파일 목록을 적은 설정 파일 하나를 만들고, 작업이 끝난 뒤 명령 한 줄을 실행하면 통과·실패·사람 확인 필요가 구분되어 나온다.
- 결과: ⚠ 일부만 확인 — 자동 테스트 37개가 모두 통과했고 실제 Claude 프로그램에서 "프롬프트 첫 글자 문제"도 재현했지만, 로그인이 없어 모델이 직접 파일을 만드는 경로는 확인하지 못했다.
