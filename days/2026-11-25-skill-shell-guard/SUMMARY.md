- 한 줄: 내려받은 스킬이 켜지는 순간 몰래 위험한 명령(비밀 파일 읽기, 인터넷에서 받은 스크립트 바로 실행 등)을 돌리지 못하게 미리 걸러 주는 장치
- 왜: Claude Code 새 버전에, 스킬 안에 적힌 명령을 실행하기 직전에 막을 수 있는 자리(훅)가 새로 생겼기 때문
- 쓰는 법: 설정에 넣을 한 덩어리를 출력해 붙여 넣고, 스킬 폴더는 점검 명령으로 미리 훑어 본다
- 결과: ✅ 잘 동작함 — 자동 테스트 27개 통과, 실제 Claude Code에서 허용은 실행되고 거절·되묻기는 실행되지 않음을 확인했다. 다만 명령을 글자로만 판단하므로 교묘하게 숨긴 명령까지 막는다고 보장하지는 않는다
