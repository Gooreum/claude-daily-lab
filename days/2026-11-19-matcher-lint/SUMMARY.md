- 한 줄: Claude Code의 자동 실행 장치(훅) 설정에서, 이름이 틀려 한 번도 실행되지 않는 조건을 미리 찾아 주는 점검 도구
- 왜: Claude Code 새 버전이 "절대 실행되지 않는 훅 조건"을 화면에서 알려 주기 시작했는데, 저장소에서 자동으로 검사할 방법은 없어서 직접 만들었다.
- 쓰는 법: 설정 파일이나 폴더 하나를 점검 도구에 넘기면 틀린 조건과 고치는 방법이 줄마다 나온다.
- 결과: ⚠ 일부만 확인 — 가짜 설정 파일 28개 시험이 전부 통과했고 이전 날짜 설정 9개를 실제로 점검했지만, 로그인이 없어 실제 Claude Code가 그 조건을 정말 건너뛰는지는 확인하지 못했다.
