- 한 줄: 코드 에디터의 Claude Code 확장이 변조됐을 때, 내 컴퓨터에 몰래 열린 뒷문이 남았는지 훑어 보는 점검 도구
- 왜: 변조된 Claude Code 확장이 자동 업데이트로 퍼져 컴퓨터에 원격 접속용 뒷문을 심었다는 보도가 나와서, 확장을 지우는 것만으로 부족한지 바로 확인할 수단이 필요했다.
- 쓰는 법: 명령 한 줄을 실행하면 설치된 확장 버전과 원격 접속 허용 목록, 자동 실행 항목을 읽기만 해서 위험도별로 알려 준다.
- 결과: ⚠ 일부만 확인 — 가짜 컴퓨터 폴더로 만든 자동 테스트 48개가 모두 통과했지만, 사건 자체가 한 건의 보도뿐이라 실제 변조 확장으로는 시험하지 못했다.
